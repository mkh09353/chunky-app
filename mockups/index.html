Open any page directly, or serve the folder (python3 -m http.server) and browse from here.

Conventions

  • Colour tokens are copied verbatim from src/mainview/index.css; nothing invents a palette.
  • DM Sans for UI, JetBrains Mono for repo names, paths, and commands — loaded from Google Fonts, with system fallbacks offline.
  • Dark is the default (class="dark" on <html>), matching the app; pages that support light flip the same class.
  • Static HTML and CSS only. Any JavaScript is cosmetic — toggles and hover wiring — never a framework or a build step.
